# Project: Enterprise Network Infrastructure Design

# Overview
This repository contains a production-grade MikroTik RouterOS configuration, fiber distribution, and centralized services designed for a small-to-medium enterprise (SME) environment.
The configuration implements dual WAN connectivity, BGP routing, LAN segmentation, VPN services, NAT, and firewall-based traffic control.

# Why Use This Solution?

This design is ideal if you need a network that is:
- Highly Available – Dual ISP with BGP ensures uninterrupted connectivity
- High Performance – Fiber backbone and CCR routing deliver fast data flow
- Secure – Firewall rules, NAT control, and restricted access reduce attack surface
- Well Organized – Segmented networks (Users, CCTV, Devices) improve control and stability
- Scalable – Easily expandable across multiple floors or buildings
- Centralized – All services (NAS, NVR, PBX, VAT) managed in one infrastructure
- Remote Accessible – VPN allows secure access from anywhere

👉 In short:
It transforms a basic network into a structured, enterprise-grade infrastructure.
